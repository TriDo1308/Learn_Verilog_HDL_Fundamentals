# Stream Cipher

## Overview

This project implements a simple stream cipher in Verilog, demonstrating the principles of pseudo-random number generation (PRNG) and its application in encrypting and decrypting data. The design includes a PRNG module, a top-level encryption/decryption module, and a testbench for verification.

## Project Structure

*   `prng.v`: Implements an 8-bit Linear Feedback Shift Register (LFSR) as a Pseudo-Random Number Generator.
*   `top_encrypt.v`: The top-level module that integrates the PRNG and performs XOR-based encryption/decryption.
*   `top_encrypt_golden.v`: A golden reference model of the `top_encrypt` module, used for verification.
*   `tb_encrypt.v`: The testbench for `top_encrypt.v`, used to verify the cipher's functionality.
*   `secret_message.txt`: A text file containing a sample encrypted message in hexadecimal format.

## Module Descriptions

### `prng.v`

This module defines an 8-bit Pseudo-Random Number Generator (PRNG) using a Linear Feedback Shift Register (LFSR).

**Parameters:**
-   `SEED`: Default 8-bit seed value (8'hCD) for the LFSR.

**Ports:**
-   `rst_n`: Asynchronous reset (active low).
-   `clk`: Clock signal.
-   `load_seed`: Control signal to load a new seed (active high).
-   `seed_in`: 8-bit input for loading a new seed.
-   `encrypt_en`: Enable signal for PRNG operation (active high).
-   `prng`: 8-bit output of the PRNG.

**Functionality:**
The LFSR generates a pseudo-random sequence based on the feedback polynomial `prng[7] ^ prng[5] ^ prng[4] ^ prng[3]`. On reset, it initializes with `SEED`. If `load_seed` is high, it loads `seed_in`. When `encrypt_en` is high, the LFSR shifts and generates the next pseudo-random number.

### `top_encrypt.v`

This module integrates the PRNG and performs XOR-based encryption/decryption.

**Ports:**
-   `rst_n`: Asynchronous reset (active low).
-   `clk`: Clock signal.
-   `load_seed`: Control signal to load a new seed into the PRNG.
-   `seed_in`: 8-bit input for the PRNG seed.
-   `encrypt_en`: Enable signal for encryption/decryption.
-   `data_in`: 8-bit input data (plaintext for encryption, ciphertext for decryption).
-   `data_out`: 8-bit output data (ciphertext for encryption, plaintext for decryption).

**Functionality:**
The module instantiates the `prng` module. It buffers the `encrypt_en` and `data_in` signals by one clock cycle. The `data_out` is generated by XORing the buffered `data_in` with the current output of the `prng` module when `encrypt_en_dly` is high. This design allows for both encryption and decryption using the same module, as XORing with the key stream twice restores the original data.

### `top_encrypt_golden.v`

This module serves as a golden reference model for `top_encrypt.v`. It implements the same encryption/decryption logic but includes the PRNG logic directly within the module, often using a Verilog `function` for the LFSR polynomial, to facilitate verification.

**Ports:** (Same as `top_encrypt.v`)

**Functionality:**
It contains an internal PRNG implementation and buffers for input signals, similar to `top_encrypt.v`. The `poly` function calculates the next state of the LFSR. The `data_out` is computed by XORing the buffered `data_in` with the internal PRNG output. This module's output is compared against `top_encrypt.v` in the testbench.

### `tb_encrypt.v`

This testbench verifies the functionality of the `top_encrypt` module by comparing its output with `top_encrypt_golden`.

**Test Scenario:**
1.  **Initialization:** Resets the system and initializes all input variables.
2.  **Encryption Phase:**
    *   Encrypts a sample plaintext message ("Red apple.") using the default PRNG seed.
    *   For each character, it calls the `encrypt_data` task and then `validate_data` to compare the DUT and golden model outputs.
3.  **Decryption Phase:**
    *   Reloads the PRNG with the same default seed (8'hCD) using the `load_new_seed` task.
    *   Decrypts the previously generated ciphertext (hardcoded in the testbench).
    *   Compares the decrypted output with the expected plaintext using `validate_data`.
4.  **Reporting:** Displays the total number of tests, successful comparisons, and errors, indicating a `TEST PASS` or `TEST FAIL`.

**Tasks:**
-   `load_new_seed(seed)`: Loads a new 8-bit seed into the PRNG.
-   `encrypt_data(data)`: Applies an 8-bit data input for encryption/decryption.
-   `validate_data()`: Compares the `data_out` from `top_encrypt` and `top_encrypt_golden` and reports the result.
