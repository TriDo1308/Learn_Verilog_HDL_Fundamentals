# Learn Verilog HDL Fundamentals

This repository serves as a comprehensive collection of Verilog HDL design examples and fundamental concepts, primarily developed through self-study based on the "Verilog HDL Fundamentals for Digital Design and Verification" course on Udemy. 

It aims to provide practical examples and structured learning materials for digital design engineers and students.

## Repository Structure

The repository is organized into several directories, each focusing on a specific aspect of Verilog HDL or digital design:

*   **`Combinational_Design/`**: Contains examples of combinational logic circuits, such as adders, comparators, decoders, encoders, multiplexers, and arithmetic logic units (ALUs).
*   **`Data_Types_and_Operators/`**: Demonstrates various Verilog data types and operators, including bitwise, logical, relational, arithmetic, and shift operators.
*   **`Design_Styles/`**: Showcases different Verilog design styles (behavioral, dataflow, structural) through examples like half-adders and full-adders.
*   **`Functions_and_Tasks/`**: Provides examples of using Verilog functions and tasks for modular and reusable code.
*   **`Memory_Design/`**: Includes designs for different types of memory modules, such as single-port and dual-port RAMs, and ROMs.
*   **`Module/`**: Basic examples demonstrating module instantiation and hierarchy.
*   **`Sequential_Design/`**: Features sequential logic circuits, including D flip-flops, latches, counters, clock dividers, and shift registers.
*   **`State_Machines/`**: Contains examples of Finite State Machine (FSM) implementations.
*   **`Structural_Design/`**: Focuses on structural modeling using gate-level primitives and module instantiations.
*   **`Verilog_Design_Examples/`**: A collection of more complex design examples, such as the Stream Cipher and Data Transfer FSM projects.
